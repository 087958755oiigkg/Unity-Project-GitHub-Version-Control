## 1. 專案資訊

- 專案名稱：Unity6000-AI-Template
- Unity 版本：`6000.3.17f1`
- Git 工具：Git for Windows（PowerShell 命令列）

## 2. Step-by-step 操作紀錄

這次有使用 AI 協助整理文件、執行 Git 操作和排除問題。

1. **準備專案**：使用課堂提供的 Unity AI Project Template v0.2，確認版本是 `6000.3.17f1`，並保留 `.gitignore`，讓 `Library/`、`Temp/`、`Obj/` 等快取不會被上傳。
2. **連接 GitHub**：用自己的帳號建立公開 Repository，再用 `git remote add origin` 連接本機專案。
3. **完成 Commit**：先用 `git init` 建立本機版本控制，再用 `git add` 選好檔案，最後用 `git commit` 記錄這次修改。
4. **Push 上傳**：完成 GitHub 登入後，用 `git push -u origin main` 把專案上傳到 GitHub。
5. **確認上傳**：在 GitHub 看到 `Assets/`、`Packages/`、`ProjectSettings/`、`.gitignore` 和 `README.md`，也確認不登入就能讀取公開專案。

## 3. 學習心得

- **Commit（提交）**：把修改記錄在自己的電腦裡，像是存一個版本，之後可以查看改了什麼，或找回舊版本。
- **Push（上傳）**：把電腦裡已經 Commit 的版本上傳到 GitHub，讓老師也能看到我的專案。
- **Pull（下載同步）**：把 GitHub 上的最新版本抓回來，整合到自己的電腦，讓本機跟上遠端的修改。
